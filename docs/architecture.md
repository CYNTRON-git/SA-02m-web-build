# Архитектура SA-02m web — карта, а не описание

**Это заглушка-указатель, и так задумано.** Полноценного архитектурного
документа у проекта нет: знание уже разложено по домам ниже, и переписывать его
сюда значило бы завести второй дом каждому факту (`PROTOCOL.md` инвариант 6).
Файл существует потому, что протокол ссылается на `docs/architecture.md` как на
системный канон и без него сессия отправляется по несуществующему адресу.

Полноценный документ (doc bootstrap по дереву) — в бэклоге; писать его нужно
отдельной задачей, а не попутно.

## Оговорка про ссылки самого протокола

`.ai-dev/PROTOCOL.md` ссылается на `docs/architecture.md` в двух разных
смыслах. Разделы `## Components`, `## Sanctioned scratch`,
`## Capability modules`, `## Integration — core / adapter` — это устройство
**самого протокола ai-dev**, они живут в его репозитории, а не здесь; искать их
в этом файле не нужно. Здесь — только системный канон проекта SA-02m, и он
разложен по таблице выше.
