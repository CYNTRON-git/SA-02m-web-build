# Аудит Pult.online — стенд 192.168.1.136, 28.09.2026

Разбор стороннего SCADA-сервера Pult.online (`/pult_server`), стоявшего на
стенде 1.136: что из него стоит взять в SA-02m и чего брать нельзя.
Исследование только на чтение — плата не менялась, бинарники не запускались,
в веб-интерфейс Pult не входили.

Где что лежит:

| Файл | О чём |
|---|---|
| `drivers.md` | драйверы (Modbus RTU/TCP/RTU-over-TCP, MQTT-клиент, OPC UA, SNMP, BACnet, HTTP, виртуальные переменные, тревоги), модель «прототип → узел → переменная» |
| `mqtt.md` | встроенный брокер `map_mqtt`, Modbus TCP slave `map_mbtcp`, туннели и шлюзы, живые проверки на :1883 и :5002 |
| `platform.md` | супервизор, JSON-RPC по unix-сокетам, самоописывающиеся конфиги, KVDB+WAL, тренды, SQLite, безопасность |
| `ui.md` | веб-интерфейс и SCADA-слой: мнемосхемы, контролы, темы, тревоги, права |

Копия дистрибутива Pult для локального изучения — Яндекс.Диск,
«ЦИНТРОН/Сборка линукс/Пульт Сервер/pult_server» (сверена с платой по
SHA-256 28.09.2026). Бэкап конфигурации платы до перепрошивки —
`D:\SA02m-images\backup136-pre-golden-20260928`.

чтение шаблона и остановка опроса молчащего прибора — контракт

Чего не копировать (кратко; доказательства — в файлах выше): анонимный
MQTT-брокер с записью на всю LAN, SSLv3/«TSSLv2» и вшитый OpenSSL 1.1.1l,
подстановка значений в `/bin/sh`, рестарт COM-порта на каждом таймауте,
собственный супервизор с бесконечным рестартом, всё под root, страница 3 МБ
без сжатия, `eval` и произвольный JS в настройках брендинга.
