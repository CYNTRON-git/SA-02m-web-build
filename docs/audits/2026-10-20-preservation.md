# Сохранение накопленных изменений перед устранением замечаний аудита

В рабочем дереве ветки `1.0.7.4` сведены накопленные изменения из 18 рабочих
деревьев. Проверенный исходный снимок содержит 141 запись файлов; исходные
деревья и снимки сохранены. Эта контрольная точка сохраняет работу перед
исправлениями аудита и **не означает готовности продукта к эксплуатации**.

База целевого дерева — `328aba0f`. Изменения сопоставлялись с исходным коммитом
каждого дерева и актуальной реализацией. Старые файлы не заменяли новые целиком:
сохранены изменения аудиомодуля, ограничения безопасности сценариев,
пересчёт энергии СЭ по версии прошивки и политика профиля установки.

## Что объединено

- Работа аудиомодуля и обработка голосовых команд, их контракт и тесты.
- Каналы MQTT, телеметрия, шаблонный опрос, доступность сценариев в Алисе,
  архивы устройств и ограничения хранения переменных сценариев.
- Сохранение порта веб-панели, доставка общей библиотеки порта и защита
  временного каталога обновляющего механизма.
- Проверки качества, диагностические сообщения, исправления окон сценариев
  и документация интеграций.
- Адаптеры Claude, OpenCode и Codex, а также промежуточные отчёты аудита.

При отключённой публикации `uptime_s` у СЭ сохранено внутреннее чтение,
обнаруживающее перезагрузку и сбрасывающее кеш версии прошивки и коэффициентов.
Единица времени СЭ остаётся `s`. Ограниченный обход переменных сценариев
объединён с существующей защитой от подмены пространства имён.

## Что сохранено отдельно

- Две временные выгрузки разговоров не входят в проектные коммиты.
- `.codex/hooks.json` из исходного дерева содержит схему и переменные Claude.
  Его оригинал сохранён в снимке, но файл не перенесён как действующий механизм
  Codex. Проверены синтаксис адаптеров и передача аргументов запуска; работа
  механических ограничений во всех реальных средах этим не доказана.
- Старое описание MTD с удалённым маршрутом `mtd_write` заменено актуальным
  контрактом шаблонных устройств; центральная проверка CSRF сохранена.
- Из `test_ce_energy_wh.py` одна проверка требует прежнего обнуления расхода
  при уменьшении счётчика. Она противоречит действующему
  [контракту архива](../contracts/devices-history-api.md): после разрыва
  суммируются неотрицательные шаги. Файл сохранён неизменённым в исходном
  снимке и исключён из этой контрольной точки. Остальные совместимые проверки
  точности и экспорта необходимо перенести в ветку исправлений; их полное
  дублирование существующими тестами не заявляется.

## Проверки и оставшиеся задачи

Проверка пробелов Git и синтаксиса JavaScript, Bash CGI и Python прошла.
Первый общий прогон выявил два конфликта объединения: потерю единицы времени
СЭ и формат диагностического режима `0600`. Оба устранены без ослабления
утверждений тестов; целевые наборы СЭ и телеметрии прошли. После исключения
устаревшего тестового файла набор устройств выполнил 227 проверок успешно.
Повтор полного набора моста выполнил 886 проверок успешно.
Общий прогон и независимая приёмка на момент составления записи ещё идут.

Нативный Git в WSL первоначально не разрешал абсолютный Windows-путь в
метаданных рабочего дерева. Из-за этого проверка идентификаторов телеметрии
видела один файл и отказала по условию полноты обхода. Такой результат
не подтверждает дефект продукта. После исправления доступности Git повтор
обошёл 1258 файлов и обнаружил отдельную существовавшую проблему проверки:
литерал регулярного выражения в `test-mqtt-acl-audio.sh` ошибочно принимается
за устаревший идентификатор телеметрии.

В новую ветку исправлений передаются также обнаруженные при сохранении задачи:

- отказ обработки голосовой команды при несовпадающем идентификаторе записи
  любого типа и корректная обработка повреждённого UTF-8 списка разрешений;
- сохранение действующего порта панели при ошибке записи миграционного файла;
- явная ошибка при недоступном журнале пропусков проверок качества;
- защита существующего сценария `vscn` перед стендовой проверкой выпуска;
- перенос совместимых проверок точности и экспорта из сохранённого файла СЭ.
- согласование отображения единицы освещённости графиков с переводом:
  две проверки сохранённого набора сейчас не проходят;
- устранение ложного срабатывания проверки идентификаторов телеметрии
  на регулярном выражении теста аудио ACL.

Симуляция восстановления I²C не доказывает форму сигнала на шине и совместимость
всех версий libgpiod. Проверки на платах, устранение дефектов OTA, владения UART
и актуальности статусов остаются отдельными этапами утверждённого плана.

Полный построчный реестр исходных файлов, контрольные суммы и журналы этой
операции находятся в сохранённых материалах
`.ai-dev/audit/remediation-20261020/`: `preservation-manifest.json`,
`preservation-integration.md`, `adapters-preservation.md` и журналы проверок.
Эти локальные материалы не входят в поставку устройства.
