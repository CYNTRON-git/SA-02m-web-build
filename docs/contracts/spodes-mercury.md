# Счётчик Меркурий по СПОДЭС

Один дом протокола. Имена MQTT, которые совпадают со СЭ-02м-3, перечислены
в `docs/MQTT_TOPICS.md`. Клиент — свой, в `opt/sa02m-spodes`. Код Gurux и
spodes-rs не импортируется и не копируется (`THIRD_PARTY.md`).

## Транспорт

Счётчик не делит провод с Modbus. `bridge_bus.validate_devices` отвечает
`mixed_framing` на каждый прибор такого COM; остальные порты живут.

- UART: `type: spodes`, без `transport` или `transport: hdlc`. 9600 8N1,
  адрес HDLC (`hdlc_address`). Идентификатор `spodes-COM2-17`.
- Сеть: `transport: wrapper`, порт по умолчанию 4059, заголовок IEC 62056-47.
  `transport: tcp` для этого типа отвергается (`type_not_tcp_capable`).
  Идентификатор `spodes-tcp-192_168_1_50-1`. Запрещённые адреса — те же,
  что у Modbus TCP.

Опрос идёт своим потоком (`HdlcPortScheduler`). `get_port` не открывает
Modbus. В реестр RS-485 счётчик не попадает.

## Ассоциации

| Роль | SAP | Что можно |
|---|---|---|
| public | 16 | паспорт, мгновенные, энергия; без шифра |
| reader | 32 | то же плюс профиль и журнал, AES-GCM набор 0 |
| configurator | 48 | ещё SET и ACTION, в том числе отключение нагрузки |

Читатель или конфигуратор без пары ключей и системного заголовка остаётся
публичным клиентом: шифрованный кадр не отправляется. Пароль и ключи в
журнале не печатаются.

## Величины

Имена контролов совпадают со СЭ там, где смысл тот же: `voltage_a`,
`power_total`, `energy_active_import`. Энергия публикуется в Вт·ч
(единица МЭК 30). Карточка «Устройства» делит на 1000 и показывает кВт·ч.
Тарифы 1…4 в живой опрос не входят.

Линейные напряжения `voltage_ab` / `bc` / `ca` читаются с
`1.0.12.7.1` / `.2` / `.3`. Если объекта нет, имя пропускается.

Профиль нагрузки и журнал событий не идут в `poll_io` и не заливают MQTT.
Файл `/run/sa02m-modbus-mqtt/<id>.profile.json` (и `.events.json`).
Чтение с сессией: `GET /api/devices/profile?device_id=`. Обмен профиля
не длиннее 2 с.

## Отключение нагрузки

Класс 70, OBIS `0.0.96.3.10.255`, методы 1 (снять) и 2 (вернуть).
Мост выполняет ACTION только при `association: configurator`. Иначе
ошибка `w` и ноль байт в линию. Кнопка на карточке — только у этой роли,
после подтверждения. Состояние рисуется по ответу счётчика, не заранее.
Алиса этот контрол не заводит.

## Установка

`sa02m_install_spodes_pkg` ставит пакет до кода моста: `scripts/05-mqtt.sh`,
`scripts/06-alice.sh`, `scripts/update-www-only.sh`. Прошивальщик пакет
не ставит и не импортирует. Нет `cryptography` — опрос остаётся публичным.

vPLC эту шину не ведёт. Имена контролов те же, что у СЭ, чтобы карта
MQTT подхватила их без правки vPLC.
