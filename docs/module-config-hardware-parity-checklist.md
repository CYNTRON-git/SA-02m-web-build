# MR/MP-02m — ручная проверка parity web vs desktop

Устройство + desktop flasher и web UI рядом. Отметить для каждого семейства из `docs/module-config-web-parity.md`.

## Общее

- [ ] Порядок вкладок: Сведения → Сеть → Реле (если есть) → **DI до DO** → AO → AI
- [ ] Live-подписи сайдбара: DI активен/не активен, DO ВКЛ/ВЫКЛ, AO напряжение, AI короткий тег
- [ ] Фоновый опрос использует `panel` + merge (активная вкладка — расширенный блок; не монолитный full на каждом тике)
- [ ] Вкладка «Сеть»: при редактировании полей фон не перезатирает введённые значения до сохранения

## Запись / регистры

- [ ] Рег. **134** общий: изменение с одной вкладки (AO / сведения) видно после обновления на другой; с DO-панели нет дублирующего поля inactivity
- [ ] DO1–6: таймерные регистры и redelay; DO7+ без таймеров (для DO16)
- [ ] DO: тест вкл/выкл, счётчики, сброс 135
- [ ] Релейные модули: запись 130/131/622; управление DO после перевода в ручной режим (или при отказе 130 — DO всё же работает)

## AI

- [ ] Выбор «режим» + подтип датчика соответствует desktop
- [ ] Калибровка скрыта/отключена для нетемпературных режимов
- [ ] 6AO6AI / 12AI: фильтры Kalman/SPS/avg/tau и слоты stor как на desktop
